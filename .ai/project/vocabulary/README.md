This layer records selected vocabulary used by Alatyr routing and review in
this fork. Canonical product terminology still comes from Doctrine public docs,
source, and tests.

## Term States

Accepted terms may be used for routing and consistency checks. Proposed terms require owner review. Deprecated, contradicted, or unknown terms must not silently replace accepted Doctrine wording.

## Vocabulary Boundaries

The vocabulary layer normalizes selected Doctrine ORM terms for assistant use. It does not replace public documentation, source symbols, or tests as canonical behavior evidence.

## Lookup Behavior

Look up `catalog.json` for compact routing, then `terms.json` for definitions and evidence. Use `data-dictionary-links.json` only for explicit links to canonical data or documentation owners.
